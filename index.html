Réglages

Les abonnements grand public (ChatGPT Plus, Gemini Advanced, Claude Pro, SuperGrok) ne peuvent pas être branchés sur un site tiers : il faut une clé API. Vos clés restent dans ce navigateur et partent uniquement vers le fournisseur concerné. Sans clé ni compte ? Utilisez l'onglet « IA locales ».

Ces IA tournent sur votre ordinateur : gratuites, sans compte, sans clé, et rien ne sort de votre machine. Installez Ollama, puis dans un terminal : ollama pull llama3.2 (ou gemma3 pour qu'elle voie aussi les images). Ouvrez ce site avec le script lancer fourni.

En mode ✦ Auto, chaque message part vers l'IA choisie pour ce type de tâche. Si elle n'est pas configurée, la première IA compatible prend le relais. Astuce : commencez un message par @gemini, @claude, @grok… pour forcer une IA.

⚖ Arbitre (mode Comparer)

Quand toutes les IA ont répondu, l'arbitre lit les réponses anonymisées (A, B, C…), les note sur 10 et désigne la meilleure.
